# Michael M. Moore

IT specialist in the Chicago area. Help desk, technical support, systems administration, and networking.

I have been working with technology for over twenty years. I started as a field technician at Comcast, then moved through software support, data and systems work, and network and systems administration for a school district. I finished a B.S. in Information Technology at Southern Illinois University in 2025.

I like the work where something is broken, someone is waiting on it, and the fix means understanding the whole chain: the user, the account, the network, the OS, and the application. I keep notes, write things down, and automate anything I have to do twice.

## What I like to do

- **Troubleshoot.** Finding the real cause instead of resetting things until they work.
- **Automate the boring parts.** PowerShell, Bash, and Python for provisioning, health checks, cleanup, and reporting.
- **Run my own lab.** Linux servers, Docker, Tailscale, Cloudflare Tunnel, firewall rules, backups, and monitoring. I host and maintain my own apps, so I deal with the same outages and updates a real environment does.
- **Learn security.** Hardening, firewall rule auditing, and hands on practice on my own systems.
- **Build small tools.** Dashboards, auditors, and web apps that solve a problem I actually had.
